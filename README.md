# Chalo Khelein Desktop Website

Desktop-first online mini game website.

Included playable games:
- Tic-Tac-Toe
- Memory Match
- Tap Challenge
- Number Guess
- Snake Mini
- Penalty Kick
- Color Catch
- Quick Math

Open index.html in Chrome or Edge.

Files:
- index.html
- style.css
- script.js

No backend is required. Scores are saved in the browser using Local Storage.
